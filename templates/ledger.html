Recomputing the chain

Clone the repository and run one command. It reads every file in predictions/, recomputes each SHA-256 over the entry with its own hash field removed, and checks that each entry's prev_hash matches the one before.

git clone {{ repo_url }}
cd proofodds
python -m proofodds.verify

Verifying an external timestamp

For any row with a proof, download the JSON and its matching .ots file into the same directory. Compare the SHA-256 shown by ots info with the JSON, then use ots verify for full verification against Bitcoin. That last step requires access to a Bitcoin Core node. A block number on this page means the matching proof contains that attestation; it does not claim this web server independently verified the Bitcoin chain.

pip install opentimestamps-client
curl -O {{ site_url }}/predictions/YYYY-MM-DD.json
curl -o YYYY-MM-DD.json.ots {{ site_url }}/timestamps/YYYY-MM-DD.json.ots
sha256sum YYYY-MM-DD.json
ots info YYYY-MM-DD.json.ots
ots verify YYYY-MM-DD.json.ots
