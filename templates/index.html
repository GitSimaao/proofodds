Why you can check this

Three properties, each enforced by code rather than by promise.

Sealed before kickoff

Each day's predictions are written to a JSON file and hashed. A file is never rewritten, and no prediction is issued for a match that has already started.

Chained

Every file carries the hash of the one before it. Alter a past prediction without rebuilding every later hash and verification fails, publicly, on the ledger. Rebuilding the whole chain instead means force-pushing over a public repository, which is visible to anyone who cloned it before. What none of this proves yet is when — that needs an external anchor, and one is being added.

Graded against the close

Not against our own opinion of a good result. Against Pinnacle's closing price, the number that has absorbed all the informed money.
