Why you can check this

Separate evidence for content, order, time and scoring.

Sealed before kickoff

Each day's predictions are written to a JSON file and hashed. A file is never rewritten, and no prediction is issued for a match that has already started.

Chained

Every file carries the hash of the one before it. Alter a past prediction without rebuilding every later hash and verification fails, publicly, on the ledger. Rebuilding the whole chain instead means force-pushing over a public repository, which is visible to anyone who cloned it before. The ledger separately labels entries with no external proof, timestamp submissions still pending, and matching proofs that contain a Bitcoin block attestation.

Generator identified

New entries record the source commit that produced their probabilities, whether those files had local changes, and a hash of the exact generator source bytes.

Graded against the close

Not against our own opinion of a good result. Against Pinnacle's closing price, the number that has absorbed all the informed money.
